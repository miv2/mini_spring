# 소셜 가입 기본 프로필 이미지 고정 설계

## 목적
- 소셜 회원가입 시 프로필 이미지가 항상 `StoredFile(id=12)`로 고정되도록 한다.

## 적용 범위
- 소셜 로그인 신규 회원 생성 시점
- 기존 회원 데이터는 변경하지 않음

## 설계 결정
- 신규 소셜 회원 생성 로직에서 `StoredFile(id=12)`를 조회해 `SocialMember.profileImage`에 세팅한다.
- `id=12`가 존재하지 않으면 서버 설정 오류로 간주하고 예외를 발생시킨다.

## 데이터 흐름
1. 소셜 로그인 성공
2. 신규 회원 판별
3. `StoredFile(id=12)` 조회
4. `SocialMember.profileImage` 세팅 후 저장

## 예외 처리
- `StoredFile(id=12)` 미존재 시 즉시 예외 발생
- 운영 설정 오류를 조기에 감지할 수 있도록 명확한 메시지 사용

## 테스트/검증
- 신규 소셜 가입 시 `profile_image_id = 12` 저장 확인
- 기존 소셜 회원은 변경되지 않음
